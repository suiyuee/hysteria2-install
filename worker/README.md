# HY2 服务器管理

网页、执行后台和节点订阅使用两条独立授权链。浏览器通过 EdgeOne 同源代理提交任务。常驻后台把任务、进度、服务器资料和节点关联保存到 SQLite，使用 SSH 操作目标机器，再使用节点 API 写入订阅。浏览器关闭后任务继续。一次执行一个任务，每台服务器保留最近任务的状态和结果。

## 三个核心操作

| 操作 | 行为 |
| --- | --- |
| 部署节点 | 先识别主机和已有安装。新机器运行此仓库随镜像附带的安装脚本。已有配置时读取当前导出，勾选节点后恢复订阅。 |
| 同步订阅 | 重新读取当前导出。按服务器、域名和 IPv4/IPv6 节点关联更新链接，尽量保留订阅里的自定义名称和顺序。只处理当前导出，不主动删除已下线的节点。 |
| 升级核心 | 运行安装脚本的 upgrade，检查主服务并记录当前和升级前版本。 |

服务器资料以 SSH 主机地址和端口查找，名称是给人和 AI 识别的备注。首次连接、指纹变化时，网页显示 SHA-256 主机公钥指纹，确认后才发送登录凭据。对同一地址重新添加时，可留空域名和凭据复用记录。更换 SSH 用户需要提供新凭据。换 IP 或用不同主机名添加会创建新记录，仍会识别已有安装。

删除订阅节点保留服务器资料及远端服务。移除服务器记录会清除其本地凭据、令牌和关联，不卸载远端服务，也不删除订阅节点。检查状态显示最近检查时间和主服务运行情况，不代表客户端实际连通性。

## 部署后台

后台放在你控制的常驻 Docker 主机；需要能够通过 SSH 访问目标，并通过 HTTPS 访问节点管理 API。目标保持原脚本要求的 Debian 13、systemd、域名和端口条件。SSH 登录用户为 root 或支持免密 sudo 的用户。

在本目录准备受限权限的 .env 文件，填写下列变量。已有数据库需要沿用原 VAULT_KEY，备份数据库时分开保管密钥。

| 配置 | 用途 |
| --- | --- |
| VAULT_KEY | Fernet 密钥，使用命令 `openssl rand -base64 32 \| tr '+/' '-_'` 生成。 |
| SERVER_ADMIN_TOKEN | 独立服务器管理口令，使用 `openssl rand -hex 32` 生成。首次进入服务器页时解锁。 |
| SUBSCRIPTION_ORIGIN | 现有订阅管理台的 HTTPS 源地址，例如 `https://hy.example.com`。 |
| NODE_API_TOKEN | 该订阅管理台已有的节点 API 令牌。 |

从 worker 目录运行 `docker compose --env-file .env -f compose.yml up -d --build`。服务监听 Docker 主机回环地址的 17861 端口。用已有 HTTPS 反向代理转发执行后台域名到该端口，保持请求 Authorization 头，关闭包含请求正文或鉴权信息的日志。EdgeOne 项目增加运行时变量 `HY2_WORKER_URL`，值为该后台的 HTTPS 源地址。前端不持有加密密钥或后台节点 API 令牌。保持单进程单实例，数据库保存在 compose 命名卷中。后台重启时排队任务继续，正在执行的任务标记为中断并提示核对，避免重复执行安装。

## 单机 AI 授权

服务器详情可查看原始 SSH 凭据。点击「授权单机」生成该记录专用的 Bearer 令牌，交给已授权的 AI。后台只持有该令牌的哈希，再次生成会替换旧令牌。

- GET /api/servers/{id} 返回地址、用户、指纹、最近状态等资料。
- POST /api/servers/{id}/credentials 返回该服务器的原始密码或私钥及可选私钥口令。
- 单机令牌无法列举其它机器，也不能提交部署或升级任务。撤销后无法再次读取。已经读取的 SSH 凭据如需作废，要在目标服务器轮换。
- 普通节点口令只管理节点。服务器管理会话使用另一枚 HttpOnly Cookie，8 小时过期。

安装失败后可重新识别。服务安装完成但订阅 API 不可用时，修复连接后点「同步订阅」即可。订阅使用 EdgeOne KV，跨设备同时写入仍受原项目 KV 一致性限制。
